# MentorMatch — EPIC Lab ITAM

Plataforma que conecta founders con mentores de la comunidad ITAM usando un algoritmo de matching inteligente. Construida para el **MAD Fellows Challenge 2026 — Track #1: Community Multiplier**.

---

## ¿Cómo correrlo?

### Backend
```bash
cd backend
source venv/bin/activate  # Windows: venv\Scripts\activate
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm run dev
```

---

## Stack

- **Frontend:** React + Vite
- **Backend:** FastAPI (Python)
- **Base de datos:** Supabase (PostgreSQL)
